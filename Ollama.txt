ollama提供短期上下文记忆的实现

聊天窗口中命令 /clear 清理聊天记录 /bye 离开

ollama pull <model>:<version> 下载模型
ollama run <model>:<version> (下载并)立即启动模型
ollama list 
ollama rm <model>:<version>
ollama run <model>:<version> --verbose 运行时输出详细信息

设置模型配置文件(无后缀) model_config 
FROM <model>:<version>
PARAMETER temperature n 
PARAMETER top_p n 
PARAMETER top_k n
SYSTEM """
系统提示词
"""

ollama create model_name -f model_config 
ollama list 
ollama run model_name

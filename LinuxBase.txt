Answer 
1.Linux 是一个操作系统内核，也是一个操作系统的统称
2.Linux 在服务器市场占绝对主导位置、开源免费、稳定可靠、安全、可定制/裁剪、命令行与脚本强大、开发友好、云计算和容器的基础
3.Linux 文件系统: 
/bin 基础命令 
/sbin 系统管理命令 
/lib /lib64 系统库文件 
/etc 系统配置文件 
/var 动态数据 
/tmp 临时数据 
/home 普通用户数据 
/root root用户数据 
/dev 设备文件 
/proc /sys 系统运行相关文件库 
/usr 用户软件仓库 apt install 
/opt 可选第三方软件仓库 
/mnt 挂载点 
4.Linux必会命令:
sudo -i 切换到root用户
mkdir -p 
rmdir 
rm -rf 
ls -la 
passwd  
whoami 
df -h 
free -h  
sudo poweroff 
which <command> 
5.Termux 是一个 Android 上的终端模拟器 + Linux 
6.Termux基本使用:
termux 在 Android 的 Linux 内核上，用 proot + chroot 构建的Linux 用户环境 --> 既不是虚拟机也不是模拟器 Termux 是跑在安卓沙盒里
termux中root是模拟root(假的 --> 因为一般正式系统,官方都会对系统root权限进行保护以确保手机的安全性)
distro --> distribution --> 发行(版)
chroot是linux系统提供的系统调用,必须root权限(内核态); proot是基于ptrace(进程跟踪)实现的用户态模拟chroot
termux-change-repo # 快速换源
termux-setup-storage # 给予空间权限 
~ (英文) 当前等于用户的家目录 
pkg install cat # 查看文件内容
pkg install openssh --> ssh username@ip -p 22 (默认22端口,服务器开启的服务不是这个要手动指定)
openssh自带scp 将本地文件上传到服务器 或 反传 
scp <local_file> username@ip:/path/ 
scp username@ip:/path/<remote_file> ~/path/
openssh自带sshd 启动ssh服务让别人连接我的主机 
sshd --> passwd # 手动设置用户密码(必须) --> 同一局域网之间可以连接 -p 8022 
非服务器公网ip由运营商提供,换个局域网就可能导致变化等
curl -L ip.cn # 查看自己当前的公网ip -s静默 -L自动重定向 
env # 查看系统环境变量 
env | grep xxx 

Tip: 
Linux中常用 ftp 工具, 以 Ubuntu/Centos 为例 
1.安装: [Ubuntu --> sudo apt-get install vsftpd] [CentOS --> sudo yum install vsftpd -y]
2.创建用户与目录: 创建一个专用用户(如: ftpuser), 并设定其家目录, 比如: sudo useradd -d /home/ftpuser ftpuser, 然后 sudo passwd ftpuser 设置密码 
3.核心配置: 编辑配置文件 /etc/vsftpd.conf 
-- anonymous_enable=NO 
-- local_enable=YES 
-- write_enable=YES 
-- chroot_local_user=YES 
4.开放防火墙: FTP默认用21端口, 需要在防火墙
5.启动服务: sudo systemctl start vsftpd, 并 sudo systemctl enable vsftpd 设置开机自启

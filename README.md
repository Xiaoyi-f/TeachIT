# TeachIT · IT 软件开发学习笔记

个人 IT 软件开发的学习笔记仓库，用于持续记录和沉淀前端、后端、数据库、运维部署、开发工具等方向的知识点。

## 这个项目是什么

- 以纯文本（`.txt`）形式记录各个技术方向的学习笔记，随学随记、持续扩充。
- 附带一个前端学习案例工程（`LearnUse/`），把前端基础知识点做成可运行的真实页面。
- 所有笔记统一放在仓库根目录，文件名即主题，方便检索和补充，无需维护目录索引。

## 目录结构

```
TeachIT/
├── *.txt                 # 各主题学习笔记（纯文本，按主题命名）
├── LearnUse/             # 前端学习案例工程（Vue 3 + Vite + TS）
└── README.md
```

## 如何添加新笔记

直接在根目录新建一个以主题命名的 `.txt` 文件即可，无需修改本 README。

## LearnUse 前端学习案例

`LearnUse/` 是一个 Vue 3 工程，用一个自包含的「FE·Lab」页面把语义化标签、表格、表单、媒体、布局、定位/层级与动效等前端基础串成真实案例。

### 技术栈

Vue 3、Vite、TypeScript、Element Plus、Pinia、Vue Router、SCSS。

### 启动

```sh
cd LearnUse
pnpm install   # 安装依赖
pnpm dev       # 本地开发（热更新）
pnpm build     # 类型检查 + 生产构建
```

> 环境要求：Node `^22.18.0` 或 `>=24.12.0`，包管理器使用 pnpm。

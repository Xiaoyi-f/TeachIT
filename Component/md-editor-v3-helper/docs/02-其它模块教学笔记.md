# 本项目其它模块讲解（不含 md-editor-v3）

> 范围：`package.json` 里除 `md-editor-v3` 外的全部依赖，以及本仓库自写模块。  
> 编辑器本体（`MdEditor` / `MdPreview` / `MdCatalog` / `config` / `NormalToolbar`）不展开，只说明「旁边怎么接」。

---

## 0. 依赖总览

| 包 | 角色 | 本仓库入口 |
| --- | --- | --- |
| `vue` | 应用框架 | `main.js`、`App.vue`、`ImageUploadToolbar.vue` |
| `mermaid` | 图表渲染 | `mermaidFix.js`、`mdEditorConfig.js`（详见另一篇笔记） |

## 1. Vue 3

### 1.1 干什么

组件化 UI、响应式状态、把页面挂到 `#app`。

### 1.2 本项目怎么用

**启动（`main.js`）：**

```js
import { createApp } from "vue";
import App from "./App.vue";

createApp(App).mount("#app");
```

**状态与组合式 API（`App.vue` / `ImageUploadToolbar.vue`）：**

| API | 用途 |
| --- | --- |
| `ref` | 模式、目录开关、滚动容器、文件 input |
| `reactive` | 主题 / 正文 / 编辑器 id；上传尺寸对话框 |

```js
const mode = ref("edit");
const state = reactive({ theme: "light", text: "...", id: "my-editor" });
```

模板里：`v-model`、`v-if` / `v-else`、`:class`、`@click`、插槽 `#defToolbars`。

### 1.3 必会点（够读本项目）

1. **`createApp(Root).mount(el)`** —— 应用入口。  
2. **`ref` vs `reactive`** —— 单值用 `ref`（模板自动解包）；对象用 `reactive`。  
3. **`<script setup>`** —— 顶层绑定直接进模板。  
4. **单文件组件** —— `template` + `script` + `style`；子组件 `import` 后即可用标签。

不必先啃 Pinia / Vue Router：本 demo 无路由、无全局 store。

## 3. Cropper.js

### 3.1 干什么

在浏览器里裁剪图片（选区域、缩放、导出 canvas / blob）。

### 3.2 本项目怎么用

同样经扩展注入：

```js
import Cropper from "cropperjs";
import "cropperjs/dist/cropper.css";

config({
  editorExtensions: {
    cropper: { instance: Cropper },
  },
});
```

编辑器内置「图片 → 裁剪」类流程会用到这个构造函数。本仓库自定义工具栏 `ImageUploadToolbar` **绕过了链接/裁剪菜单**，改为「选文件 → 设宽高 → 插入」；但扩展仍注册，避免编辑器其它图片能力缺依赖。

### 3.3 必会概念

```js
const cropper = new Cropper(imgElement, { aspectRatio: 16 / 9, viewMode: 1 });
const canvas = cropper.getCroppedCanvas();
```

记住：`new Cropper(img, options)` + 配套 CSS；本项目只负责「把类交进去」。

## 4. Axios

### 4.1 干什么

基于 Promise 的 HTTP 客户端；浏览器里发 GET/POST、带 headers、处理错误都很方便。

### 4.2 本项目怎么用（`App.vue` → `onUploadImg`）

流程：

1. 对每个文件建 `FormData`，字段名 `file`  
2. `axios.post("/api/img/upload", form, { headers: { "Content-Type": "multipart/form-data" } })`  
3. 成功：用返回 `url`（若有）或文件本身写入本地图库，正文放 `local://id`  
4. **任意失败**：整批走本地兜底 `callback(files.map(file => toLocalSrc(putImage(file))))`

```js
axios.post("/api/img/upload", form, {
  headers: { "Content-Type": "multipart/form-data" },
});
```

没有真实后端时，demo 仍能本地预览图片——这是 axios 失败分支 + `imageStore` 的设计。

### 4.3 必会点

| API | 用途 |
| --- | --- |
| `axios.get(url)` / `axios.post(url, data)` | 常用方法 |
| `FormData` + `multipart/form-data` | 文件上传 |
| `.then` / `await` + `try/catch` | 成功与失败 |
| `headers` | 声明内容类型等 |

对比：也可用原生 `fetch`；本项目选 axios 主要是写法统一、错误进 `catch` 清晰。

## 5. `@vavt/v3-extension`

### 5.1 干什么

面向 `md-editor-v3` 的官方周边扩展组件（表情、导出 PDF 等）。

### 5.2 本项目怎么用（`App.vue`）

```js
import { Emoji, ExportPDF } from "@vavt/v3-extension";
import "@vavt/v3-extension/lib/asset/Emoji.css";
import "@vavt/v3-extension/lib/asset/ExportPDF.css";
```

插在编辑器自定义工具栏：

```vue
<template #defToolbars>
  <Emoji :theme="state.theme" title="表情" />
  <ExportPDF :modelValue="state.text" :theme="state.theme" title="导出 PDF" fileName="markdown" />
  <ImageUploadToolbar ... />
</template>
```

`toolBars` 里用数字占位对齐 `defToolbars` 顺序：

| 数字 | 对应组件 |
| --- | --- |
| `0` | 第 1 个：`Emoji` |
| `1` | 第 2 个：`ExportPDF` |
| `2` | 第 3 个：`ImageUploadToolbar` |

### 5.3 必会点

1. **组件 + 各自 CSS 都要引**，否则图标/弹层样式缺失。  
2. `Emoji` 跟主题走：`:theme="state.theme"`。  
3. `ExportPDF` 吃当前 Markdown 字符串：`:modelValue="state.text"`，并设 `fileName`。  
4. 与内置工具栏字符串（如 `"bold"`）混排时，**数字 = defToolbars 下标**。

## 6. Vite + `@vitejs/plugin-vue`

### 6.1 干什么

| 包 | 作用 |
| --- | --- |
| `vite` | 开发服务器（ESM 秒启）、生产打包 |
| `@vitejs/plugin-vue` | 让 Vite 编译 `.vue` 单文件组件 |

### 6.2 本项目配置（`vite.config.js`）

```js
import { defineConfig } from "vite";
import vue from "@vitejs/plugin-vue";

export default defineConfig({
  plugins: [vue()],
  server: { port: 5173 },
});
```

### 6.3 npm scripts

| 命令 | 含义 |
| --- | --- |
| `npm run dev` | 开发：`http://localhost:5173/` |
| `npm run build` | 打生产包到 `dist/` |
| `npm run preview` | 本地预览构建结果 |

### 6.4 必会点

1. 根目录 `index.html` 是入口，经 `<script type="module" src="/src/main.js">` 拉起应用。  
2. `import xxx from "./App.vue"` 能工作，是因为 `plugin-vue`。  
3. `import "某包/xxx.css"` 由 Vite 直接处理样式依赖。  
4. `"type": "module"`（`package.json`）表示 Node 侧也按 ESM 解析。

## 7. 本地模块（非 npm，但必懂）

### 7.1 `imageStore.js` —— 本地图片短链

问题：把 `blob:` 或超长 URL 直接写进 Markdown 很丑、难改尺寸。

方案：

| 函数 | 作用 |
| --- | --- |
| `putImage(fileOrUrl)` | 存进内存 Map，返回 `img_1` 这类 id |
| `toLocalSrc(id)` | 得到 `local://img_1` |
| `parseLocalId(src)` | 从 `local://...` 解析 id |
| `getImageUrl(id)` | 取真实可展示 URL（含 `URL.createObjectURL`） |
| `buildImagePlaceholder(id, w, h)` | 生成带 width/height 的 `<img>` 占位 |
| `resolveLocalImages(html)` | 渲染前把 HTML/Markdown 里的 `local://` 换成真实地址 |

预览链路：`markdown-it` 出 HTML → `resolveLocalImages` → 浏览器才能显示图。

### 7.2 `mermaidFix.js` —— 多图可靠渲染

见 Mermaid 专项笔记。导出：`patchMermaid`、`applyCachedMermaid`、`installMermaidPreviewFix`。

### 7.3 `mdEditorConfig.js` —— 全局编辑器配置副作用

副作用模块：在 `main.js` / `App.vue` 里 `import "./mdEditorConfig"` 即执行：

1. 打补丁并安装 Mermaid fix  
2. `config({ editorExtensions, markdownItConfig })`  
3. 空行占位 `preserveBlankLines`  
4. 本地图 `bindLocalImageRenderer`  
5. 渲染后：`applyCachedMermaid(resolveLocalImages(...))`，并同步 `srcLines`

### 7.4 `ImageUploadToolbar.vue` —— 自定义上传条

| 步骤 | 行为 |
| --- | --- |
| 点击 | 触发隐藏 `<input type="file" accept="image/*" multiple>` |
| 选文件 | 调父组件传入的 `onUploadImg` |
| 弹窗 | 设 width / height（px），height 可空 |
| 插入 | `insert()` 写入 `buildImagePlaceholder(...)`，前后加空行避免多图挤一行 |

依赖编辑器提供的 `NormalToolbar` + `insert`（属编辑器扩展约定，此处不展开 API 细节）。

## 8. 模块协作图（去掉编辑器内部）

```text
main.js
  ├─ mdEditorConfig.js
  │    ├─ cropperjs + css      → editorExtensions.cropper
  │    ├─ mermaid + mermaidFix → stub / 缓存 / 补画
  │    └─ imageStore           → markdown-it 图片规则 + HTML 替换
  ├─ mermaidFix.install...
  └─ createApp(App)
       App.vue
         ├─ vue ref/reactive
         ├─ axios 上传（失败 → imageStore）
         ├─ @vavt Emoji / ExportPDF
         └─ ImageUploadToolbar → imageStore

vite + plugin-vue 负责把以上全部在浏览器里跑起来
```

## 9. 建议学习顺序

1. **Vue 3** 基础（`ref` / `reactive` / SFC）—— 能读 `App.vue`  
2. **Vite** 脚本与 `vite.config.js` —— 会启动项目  
3. **imageStore + axios** —— 理解无后端也能插图  
4. **cropperjs** —— 知道「实例注入扩展位」模式  
5. **@vavt/v3-extension** —— 自定义工具栏数字占位  
6. **mermaid + mermaidFix** —— 对照 `01-Mermaid...` 笔记  

读完应能回答：每个 npm 包在仓库里**出现在哪几个文件、解决什么问题、缺了会怎样**。

--> 常用Dos命令有啥?
17.Windows 常用 Dos 命令 
18.Mac 常用 Dos 命令 


Answer 
1.Dos == Disk Operating System 磁盘操作系统 系统命令控制界面 
2.Shell 用户与操作系统内核之间的 "交互工具" [命令 -> Shell解释 -> Dos 内核执行 -> 硬件干活]
3.环境变量即操作系统中一组 "键值对" 配置, 供系统和程序读取 
4.环境变量PATH用于告诉系统寻找可执行程序位置的路径, 进而实现任意位置执行可执行程序可以正常启动而不被位置限制
5.系统盘是操作系统存放核心配置数据的存储空间, 对于系统的正常运行有着密不可分的关系 
6.用户 = 操作系统中一个 "身份账户", 主要用于隔离资源、配置和权限 
7.文件扩展名用于标识文件类型    
8.隐藏文件默认不显示, 通常用于存储配置数据或重要数据 且 通常以 . 开头 
9.Windows常用Dos命令: dir cd .. cls
10.Mac常用Dos命令: ls cd pwd mkdir rmdir cp mv rm cat clear  
11.CDN 内容分发网络, 设定好节点存储静态资源从而提高各个地区的资源访问速度 
12.介于应用程序和操作系统 / 数据库 / 网络底层之间的一类软件，不直接给用户用，专门帮应用做通用能力，解耦业务代码
13.代理服务器站在服务端一侧，接收客户端请求，再转发给后端真实业务服务器；客户端只知道代理，不知道后端真实机器
14.同一套服务，部署多台一模一样的服务器，组成一组就是集群，一个节点倒下只是影响到整体强壮，不影响实际功能 
15.把一个大系统拆成多个不同的子模块，部署在不同机器上，分工协作共同完成业务
16.微服务是分布式架构的一种最佳实践: 把单体大应用，按照业务域，拆分成独立、松耦合、可独立开发、独立部署、独立扩容的小型服务，每个服务只负责单一业务能力（用户服务、订单服务、商品服务），服务之间通过 API/RPC 通信
--> 云原生（Docker 容器、K8s、服务网格、可观测、CI/CD）就是为微服务而生，解决微服务的服务发现、弹性扩缩容、滚动发布、故障隔离、批量运维这些痛点

1. 接口逆向：破解第三方 API（抓包与复现）
就像你刚才用 curl 调用的那个 API，你是怎么拿到 Authorization: Bearer xxx 这个 token 的？
抓包：用浏览器 F12 开发者工具（Network 面板）、Charles、Fiddler 或 Wireshark。看网页是怎么发请求的，把 Headers、Body 全抄下来。
代码逆向：如果前端做了加密（比如密码不是明文传，而是被 JS 加密了），你需要去 Chrome 里打断点，找到对应的 JS 函数，把加密逻辑扒下来，用 Python 或 Java 重写。
防封控：逆向 API 后，通常要处理限流、IP 代理、Cookie 池等问题。

2. 前端逆向：扒别人的网页/小程序
静态网页：直接 F12 看源码，或者用 wget 把整个网站爬下来。
Vue/React 站点：JS 代码会被打包混淆（一堆 a, b, c 变量）。你需要用 Source Map 还原，或者用 AST（抽象语法树）工具（如 Babel）去反混淆。
微信小程序：下载小程序的 .wxapkg 包，用脚本解包，就能看到前端的代码和调用的接口。

3. 数据库/后端逆向：从数据到代码
数据库逆向：如果你只有 MySQL 的库表数据，没有 Java 代码，你可以用 MyBatis-Plus 的代码生成器（或者 IDEA 里的 Database 插件），直接根据表结构逆向生成 Java 的 Entity、Mapper、Service、Controller。
架构逆向：如果你拿到一个别人做好的系统，你可以通过查看 Nginx 日志、Docker 镜像（docker inspect）、甚至反编译 .jar 包（用 JD-GUI 或 CFR 工具），来弄清它的微服务架构和业务逻辑。

4. 二进制/软件逆向：破解软件
用 IDA Pro、Ghidra、OllyDbg 等工具，把编译好的 .exe 或 .so 文件反汇编成汇编代码，找注册码验证逻辑（俗称“破解”）。

⚠️ 法律与道德红线
必须要提醒一句：逆向别人的商业系统、破解软件、绕过付费限制、抓取受保护的隐私数据，在很多国家和地区（包括中国）是违法的（侵犯著作权、破坏计算机信息系统罪、非法获取计算机信息系统数据罪）。

合法的逆向场景通常包括：
安全测试（渗透测试、漏洞挖掘），但需要授权。
学习开源项目的底层原理。
恢复自己丢失的代码或数据。
接口对接时，对方没有提供文档，只能自己抓包分析。

浏览器断点: 一旦程序执行到设置的断点位置，它就会在那里暂停，使得开发人员可以逐步执行代码、观察变量的值，并进行其他调试操作，帮助我们定位数据加密的位置
